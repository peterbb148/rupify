## Summary

Improve UCP scoring guidance in SpecOps so users can classify actors, use cases, and factor scales
more naturally and with fewer corrections.

Parent epics: #10, #9

## Scope

- clearer explanations of actor complexity
- clearer explanations of use-case complexity
- better 0-5 factor guidance
- interview prompts that correct common user intuition mismatches without being heavy-handed

## Acceptance Criteria

- users can answer UCP questions without needing major post-hoc normalization
- actor/system complexity distinctions are explained clearly enough to avoid common reversals
- factor scales are explained in a compact way that still supports defensible scoring
- the output keeps assumptions and uncertainty explicit
