## Summary

Deliver the first end-to-end SpecOps workflow for software requirements discovery: interview, model,
requirements spec, use-case model, and deterministic UCP estimate.

## Scope

- orchestrator skill
- discovery, use-case, and UCP subskills
- canonical model
- artifact renderer
- UCP engine

## Acceptance Criteria

- one canonical model drives all generated artifacts
- the workflow stops clearly when estimation inputs are insufficient
- the UCP calculation path is deterministic
