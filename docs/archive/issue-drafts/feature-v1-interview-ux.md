## Summary

Improve the SpecOps interview UX so users are not forced into replying to large walls of text or
inline complexity matrices that are hard to answer accurately in a terminal/chat flow.

Parent epics: #10, #9

## Scope

- reduce wall-of-text interview prompts
- introduce tighter grouped rounds and response formats
- improve answer ergonomics for role, workflow, and metadata capture
- investigate whether app-level structured question UX can be used safely and truthfully

## Acceptance Criteria

- the interview flow asks shorter grouped questions with clearer expected answer shapes
- complexity and factor inputs can be answered without awkward inline editing of large prompt blocks
- the workflow explicitly distinguishes between what skill-native UX can do and what would require
  app/plugin support
- the improved interview remains traceable to the canonical model
