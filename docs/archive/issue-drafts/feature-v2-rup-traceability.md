## Summary

Implement the V2 traceability layer for SpecOps so discovery, requirements, analysis, design, and
generated UML artifacts stay connected in a RUP-aligned way rather than becoming disconnected views.

Parent epic: #8

## Scope

- traceability links across discovery, requirements, analysis, and design
- explicit RUP-aligned work-product relationships
- artifact lineage from interview input to generated outputs

## Acceptance Criteria

- the model and generated outputs preserve traceability across the main RUP-aligned views
- generated UML artifacts can be traced back to discovery and requirement sources
- the workflow makes gaps in traceability visible instead of hiding them
