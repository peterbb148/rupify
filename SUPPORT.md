# Support

## How To Get Help

Use GitHub Issues for:

- bug reports
- workflow confusion
- documentation problems
- feature requests

When filing an issue, include:

- what you were trying to do
- which command or skill you used
- the model or fixture path involved, if relevant
- the exact error output, if any

## What This Repo Supports

Rupify currently supports:

- canonical model driven rendering
- replayable interview fixtures
- formal Markdown artifact generation
- Mermaid generation for supported views
- local skill workflows in Codex-style environments

## What This Repo Does Not Yet Promise

- hosted service support
- guaranteed compatibility with non-Codex agent environments
- strict UML interchange formats
- document ingestion as a fully productized workflow
