# Complexity Rubric

## Actor Complexity

- `simple`: another system interacting through a defined API
- `average`: a human using a protocol or text interface
- `complex`: a human using a graphical interface with richer interaction

## Use-Case Complexity

- `simple`: up to 3 transactions
- `average`: 4 to 7 transactions
- `complex`: more than 7 transactions

If the transaction count or interaction mode is unclear, leave the value unresolved and ask.
