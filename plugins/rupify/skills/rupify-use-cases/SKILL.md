# Rupify Use Cases

## Overview

Use this skill after the initial discovery pass to structure actor and use-case detail.

## Responsibilities

- refine actor definitions and interaction style
- structure main success scenarios and extensions
- classify actors and use cases for UCP scoring using the rubric in
  `references/complexity-rubric.md`
- ensure the use-case model and UCP inputs stay aligned

## Rules

- use the canonical model as the editing surface
- keep scenario descriptions concrete and actor-centric
- if complexity is unclear, mark it as unresolved rather than guessing
